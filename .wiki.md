# Project Summary

AGNAVELIS is a B2B export website for silver nitrate applicator sticks manufactured in Türkiye by Genco Tıbbi Cihazlar San. Tic. Ltd. Şti. It provides product, manufacturer, and professional-use information for medical distributors, wholesalers, importers, and healthcare suppliers. The site has no ecommerce, pricing, or cart functionality.

Visitors can request a quote through a B2B form on the Contact page or use WhatsApp. Quote requests are handled by a backend API and intended to be emailed to `export@agnavelis.com`; sending is disabled until SMTP connectivity and real email delivery are verified. Email links remain available.

GA4 uses measurement ID `G-7TMC0025H8` and loads only after analytics consent. Quote and WhatsApp events are configured without sending form data or WhatsApp message URLs to analytics.

# Project Module Description

- **Home**: B2B product positioning, manufacturer information, documentation highlights, FAQs, and quote and WhatsApp calls to action.
- **Product**: Product specifications, intended purpose, warnings, storage guidance, IFU links, wooden-versus-plastic clarification, and sourcing information. Product length and pack quantity are confirmed per order and destination market.
- **Manufacturer**: Information about Genco Tıbbi Cihazlar, manufacturing, and export.
- **Quality & Documentation**: Product brochure, IFU, technical and packaging information, and document request options.
- **Instructions for Use**: IFU landing page with document summary, safety notice, and document access.
- **Contact and quote form**: B2B quote request form, WhatsApp contact, and email links. The form validates submissions on the server and includes basic spam and duplicate-submission protections. From and To are `export@agnavelis.com`; Reply-To uses the visitor’s email. Submission remains disabled until SMTP delivery is verified.
- **Shared layout and consent**: Responsive navigation, footer, SEO metadata, breadcrumbs, WhatsApp action, and analytics consent controls.
- **Backend API**: Authentication, health, quote, quote-request, settings, storage, and user endpoints, with database models and migrations.
- **SEO and discoverability**: Prerendered route HTML, canonical metadata, Open Graph/Twitter tags, JSON-LD, sitemap, robots file, and `llms.txt`.

# Usage

Install frontend dependencies and run the development server:

```bash
cd app/frontend
npm install
npm run dev
```

Run frontend checks and create the production build:

```bash
npm run lint
npm run build
```

Install backend dependencies and run the API locally:

```bash
cd app/backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

Configure backend environment variables through the platform’s secure configuration. Quote email delivery requires SMTP settings and `QUOTE_EMAIL_ENABLED`; keep sending disabled until SMTP connectivity and a real delivery test both succeed. Do not put credentials in source files or share them in chat.

The SMTP variables were reported as defined in the checked backend environment, but a connection test returned `SMTPServerDisconnected`. This does not establish that the password is incorrect. Real delivery and GA4 DebugView were not verified. The current changes have not been published.

The quote form and analytics behavior passed lint, production build, Python syntax checks, and controlled browser/API tests. Those tests do not constitute verification of real SMTP delivery.
